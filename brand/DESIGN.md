# moraine: brand tokens

The docs site is the main surface, so the mode is Read: structure first, then a reading
experience worth staying in. The home page is allowed one bolder moment (BOLD 7 there): the
heavy display line and the commit drawn as streams turning into beds. Everything else is quiet.

## Subject inventory

What belongs to moraine and to no other database:

1. The name: a moraine is the ridge of rock a glacier carries and leaves behind, deposited layer
   by layer.
2. Many glaciers feed one ridge: tributaries flow side by side and drop their load in one place.
3. Strata: sediment laid down in order, oldest at the bottom, never rewritten in place.
4. Ochre: the yellow iron oxide that stains glacial till and weathered moraine stone.
5. Umber: the dark earth under it.
6. The Delta log: numbered entries, one conditional PUT each; the version is the layer count.
7. Concurrent writers with no server between them, ordered only by who lands the next entry.
8. Sorted sediment: data files sorted by key, so readers skip most of them.
9. Durability: nothing is updated in place; files are immutable.

The concept comes from items 2, 3 and 7: **writers come in side by side and leave as ordered
beds, and the newest bed is ochre**. The mark, the wordmark's i, the header edge, the banners and
the home page's commit diagram use it, and nothing else does.

## Colour

All of this is generated by `assets/src/build.py`, which writes `docs/stylesheets/tokens.css` and
stops if any text pairing below falls under WCAG AA (4.5:1 for text, 3:1 for the focus ring).

```yaml
  accent:          ["#835A00", "#F9C23C"]  # ochre-700 / ochre-300: links, current nav item, primary button
  accent-press:    ["#5E4108", "#FFDA75"]
  on-accent:       ["#FDFCF9", "#15110A"]
  accent-tint:     ["#F6E7BF", "#3D2F10"]  # selection, highlighted code lines
  border:          ["#DCD5C6", "#3E3424"]  # tables and inputs only
  success:         ["#1F6E5A", "#7FCBB4"]  # never the accent
  warning:         ["#A3431A", "#F2915C"]  # burnt orange, kept apart from ochre
  error:           ["#B0262D", "#F28C86"]
  focus:           ["#835A00", "#FFDA75"]  # 2 px ring, 2 px offset
  beds:            ["#835A00", "#C98B14", "#F9C23C"]  # oldest, middle, newest; the same in both themes
```

The beds are the one place where the ramp is used as a sequence. I fixed them to the same three
stops in both themes so the rule is simple: the newest bed is always ochre-300, and every older bed
is darker. On the umber ground the old beds sink back; on parchment they gain weight. Either way
the eye goes to the newest one first.

Code highlighting uses the same tokens: keywords in the accent, strings in success, numbers and
constants in warning, comments in ink-muted.

Light is the default because most of the reading happens next to an editor in daylight; dark is
offered because the same people read at night. Both are verified.

## Typography

```yaml
typography:
  families:
    display: { name: "Bricolage Grotesque", source: "self-hosted, SIL OFL", axes: "wght 500-800, opsz 12-96, wdth 88" }
    text:    { name: "Instrument Sans", source: "self-hosted, SIL OFL", axes: "wght 400-700, wdth 100" }
    code:    { name: "Spline Sans Mono", source: "self-hosted, SIL OFL", axes: "wght 300-700" }
    fallback: "ui-sans-serif, system-ui, sans-serif / ui-monospace, SFMono-Regular, Menlo, monospace"
  scale:                            # rem of Material's root (20 px at laptop widths)
    display: { size: "clamp(2.4rem, 5vw, 3.6rem)", weight: 800, lineHeight: 1.02, tracking: "-0.025em" }  # home only
    title:   { size: "1.7rem",  weight: 750, lineHeight: 1.1,  tracking: "-0.02em" }   # h1
    heading: { size: "1.2rem",  weight: 700, lineHeight: 1.25, tracking: "-0.01em" }   # h2
    body:    { size: "0.85rem", weight: 400, lineHeight: 1.6, measure: "70ch" }        # h3 is 0.9rem at 700
    small:   { size: "0.7rem",  weight: 400, lineHeight: 1.5 }                         # captions, footer, table notes
  numerals: tabular-nums in tables and benchmark figures
  rules:
    - headlines two lines or fewer at 375 / 1024 / 1920
    - sentence case everywhere; no all-caps labels, no eyebrows
    - monospace only for code, paths and identifiers
```

I chose Bricolage Grotesque for its heavy, slightly condensed cut with ink traps: at weight 780
and width 88 it has the density of the mark's bands and enough quirk to be recognisable without
the mark. It is too characterful for paragraphs, so Instrument Sans carries the text: plain,
open and calm at 17 px. Spline Sans Mono stays for code.

## Mark

- **Idea.** Concurrent writers become one ordered log. Three bands of ice come down side by side,
  parallel like writers, and each turns a quarter circle into a horizontal bed, stacked like log
  entries. The outermost stream becomes the oldest bed at the bottom; the innermost becomes the
  newest bed on top, in ochre. It is also what a glacier does: many streams of ice feed one
  deposit, laid down in order.
- **Drawing.** On a 256-unit grid, three bands share one centre: 40-unit stroke, 16-unit gap,
  24-unit margin, ends cut flush, so the mark is a square with 56-unit straight legs before the
  turn.
- **Small drawing.** At 16 and 32 px I use a second drawing on the 16 px pixel grid: 2 px bands,
  1 px gaps, a 1 px margin and 6 px straight legs. Scaling the large mark down, or thickening its
  bands, shortens the legs until only concentric arcs are left, and those read as a wifi symbol.
  The legs are what make it read as streams turning into beds; I tested both drawings at 16, 32 and
  64 px beside a wifi glyph and a corner bracket, and this one reads as neither.
- **Wordmark.** `moraine` in Bricolage Grotesque, weight 780, width 88, optical size 96, tracking
  -0.012em, with the font's kerning, converted to outlines. The i's dot is one turned bed: a square
  as wide as the stem with its lower-left corner a full quarter circle, in the newest bed's ochre.
  The x-height is 0.52 of the mark and the baseline sits on the mark's lowest bed.
- **Files.** `assets/logo.svg`, `logo-dark.svg` (the same drawing; the beds work on both grounds),
  `wordmark.svg`, `wordmark-dark.svg`, `favicon.svg` (the small drawing), `banner-light.svg`,
  `banner-dark.svg` (1280 x 320, each on its own ground, for the README), `social-preview.png`
  (1280 x 640, dark) and `apple-touch-icon.png` (180 x 180, dark).
- **Do not** recolour the beds, reorder them, add a gradient or an outline, round the flush ends,
  or rotate the mark: the streams always come down from the top and turn to the right.

## Principles

1. The turn is the only decoration: it appears in the mark, the wordmark's i, the header edge and
   the commit diagram, nowhere else.
2. Numbers are evidence. Benchmark figures are copied, not rounded into slogans, and the losses
   are shown next to the wins.
3. Earth stays quiet. One accent, tone steps for structure, no shadows at rest, no cards.
4. Code is the picture. Examples compile against the real API.
